# CIT 324 🧪 Simulation and Modeling Sessional

Lab codes and exercises for **CIT 324: Simulation and Modeling Sessional**.

## Folder Structure

- **`Area of Irregular Points.py`** — Monte Carlo simulation for estimating the area of irregular shapes.
- **`Gambling.py` / `Gamblers Ruin.py` / `Gamblers Ruin Easy.py`** — Gambler's Ruin simulation.
- **`Mam Part/`**
  - **`First Question/`** — Random number generation (0 to 1), sample statistics (mean, minimum, standard deviation), random seed effects, and large sample comparison ($N = 100$ vs $N = 10000$).
  - **`Second Question/`** — Service counter simulation: exponential inter-arrival times ($\text{mean} = 5\text{ min}$) and uniform service times ($U(2, 8)\text{ min}$), histograms, and comparison with theoretical values.
